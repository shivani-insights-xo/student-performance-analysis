# 📊 Student Performance Data Analysis

This project analyzes student performance data using Python.

# 🔍 Objective
To explore factors affecting student academic performance using data analysis techniques.

# 📁 Dataset
Student performance dataset containing academic and personal attributes.

# 🛠 Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn

# 📊 What I did
- Data cleaning
- Exploratory Data Analysis (EDA)
- Data visualization
- Insights extraction

# 📈 Key Insights
- Study time impacts performance
- Past scores strongly correlate with final grades
- Attendance plays an important role

# 🚀 How to run
pip install -r requirements.txt  
python main.py
